# 数据库目录

本目录集中管理可审计的数据设计资料，不替代各服务自己的Flyway迁移脚本。

## 逻辑数据库

| 数据库 | 归属服务 | 数据范围 |
| --- | --- | --- |
| `road_training_admin` | 管理基础服务 | 用户、企业、组织、角色、权限等基础信息 |
| `road_training_training` | 培训业务服务 | 课程、培训计划、考试、试题和试卷 |
| `road_training_learning` | 学习监管服务 | 学习会话、有效学时、抽验任务和异常记录 |

每个业务服务使用独立数据库账号，且账号只被授予归属逻辑库的必要权限。各服务只能通过自己的数据访问层读写归属数据库，禁止跨库联表查询；跨服务数据通过Dubbo接口或RabbitMQ事件传递。

## 目录约定

- `design/`：ER图、表设计和索引说明。
- `seed/`：不包含真实个人信息的演示数据说明。
- 实际建表脚本放入对应后端服务的`src/main/resources/db/migration/`，由Flyway按版本执行。

## 数据安全

- 禁止提交生产数据、真实证件号、人脸照片、密码和访问令牌。
- 开发演示数据必须脱敏或完全虚构。
- 人脸核验结果优先保存核验状态、置信度和审计信息，不保存不必要的生物特征原始数据。
