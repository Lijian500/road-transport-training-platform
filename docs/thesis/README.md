# 论文材料

已整理[论文设计与答辩材料](design-and-defense.md)，包括需求、架构、逻辑ER、学习/抽验时序图、实现说明、实验边界与8分钟答辩讲稿。测试事实引用[验收报告](../test/acceptance-2026-09-07.md)。

本目录用于保存与毕业论文配套、可公开的项目材料：

- 需求分析和可行性分析；
- 总体设计与详细设计；
- 核心流程、状态机和时序图；
- 数据库设计；
- 系统实现说明和关键截图；
- 测试方案、测试结果及分析；
- 论文中图表与仓库实现的对应关系。

论文材料不得复制原商业系统的代码、数据库结构、界面资源、密钥或客户数据。引用第三方资料时应标明来源并遵守许可证。
