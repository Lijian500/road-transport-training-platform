# 论文材料

后续论文写作和排版请先阅读[论文写作与格式规范](论文写作与格式规范.md)。该规范依据学校提供的 Word 写作指南整理，区分原文要求、建议和待确认事项，并提供定稿检查清单。

论文更新先阅读[需求变更与论文更新总索引](../changes/README.md)，按条目定位相关代码及章节；[首次回溯记录](../changes/2026-09-13-since-09-07.md)包含 9 月 7 日后的提交、未提交源码及文件覆盖清单。小更新只处理相关段落和图表；整体基线不明、影响无法界定或定稿时，先核查整个项目的一致性。

已整理[论文设计与答辩材料](design-and-defense.md)，包括需求、架构、逻辑ER、学习/抽验时序图、实现说明、实验边界与8分钟答辩讲稿。历史测试事实引用[2026-09-09 验收报告](../test/acceptance-2026-09-09.md)，[09-07 报告](../test/acceptance-2026-09-07.md)保留其历史范围；旧测试结论不覆盖后续未提交代码。

[Word 初稿](基于Dubbo的道路运输企业在线培训系统设计与实现_论文初稿.docx)尚未核对其代码基线。本次仅补记及修正技术材料，Word 未修改；首次记录的条目保持“待核对”。更新论文后必须回填实际文件版本、处理编号、章节及代码范围。

本目录用于保存与毕业论文配套、可公开的项目材料：

- 需求分析和可行性分析；
- 总体设计与详细设计；
- 核心流程、状态机和时序图；
- 数据库设计；
- 系统实现说明和关键截图；
- 测试方案、测试结果及分析；
- 论文中图表与仓库实现的对应关系。

论文材料不得复制原商业系统的代码、数据库结构、界面资源、密钥或客户数据。引用第三方资料时应标明来源并遵守许可证。
