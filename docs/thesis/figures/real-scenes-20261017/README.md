## 证据边界

不同原图中的配置开关、日期和页面状态可能不同。例如，课程规则截图中的“允许拖动”关闭，而计划快照中显示“是”；计划基础信息与学员详情显示的开始日期也不同。各图仅支持其实际可见的功能展示，不能串成同一次、同状态的完整验收过程，也不能依据文件名或本次整理日期推断实际测试日期。

签到与抽验摄像头预览不等于已经提交或核验成功；播放器暂停截图不等于持续播放验证。保留截图中的原始学时、播放位置和状态，不据此推导计时准确性或真实闭环结果。
