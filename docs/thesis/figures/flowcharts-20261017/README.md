## 符号与业务含义

参照导师指定的[流程图画法资料](https://blog.csdn.net/weixin_44917390/article/details/121357607)，两图均只设一个开始节点，开始与结束采用椭圆，普通处理采用矩形，判断采用菱形并分别标明“是／否”，控制流采用有向折线且不交叉。

- 图4-7区分同步受理和按需异步同步。当前身份及绑定通过后才查询历史请求；已受理请求返回原确认结果，不重复累计。新请求通过序号、状态、任务及位置校验后，按服务端规则计算学时并在事务内保存会话、事件及按需Outbox。上报超时可能成功受理、暂停会话且本次计入0学时，不能一概视为拒绝。虚线箭头“按需异步”表示已提交数据触发后续消息同步；浏览器的ACK和学时确认无须等待消息发布或消费。任务事件至少一次投递、失败按策略重试，培训服务幂等去重并按事件更新任务。
- 图4-8以双竖线矩形表示“学习与过程核验”预定义子流程，右侧括注及无箭头虚线为子流程说明。断线恢复、抽验触发／重试／终止及手动继续保留在注释中，避免附加子图重复设置开始和结束。主线显式判断全部课程完成、是否考试及考试通过；仅学习任务跳过考试，考试未通过不能进入培训完成。档案按任务动态聚合，未完成任务和终止会话的过程留痕同样可查，不表示结业后才生成独立文件。

原素材来源为[反馈一学习流程图](../advisor-20261016/learning-flow.drawio)与[反馈二核心业务链图](../advisor-two-20261016/core-business-flow.drawio)。本轮仅规范图示及章节归属，未改业务代码，未新增实验数据，也不覆盖历史图库或其验收结论。

