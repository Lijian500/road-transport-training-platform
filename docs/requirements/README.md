# 需求说明

本目录用于沉淀论文精简版系统的需求基线。

需求变化统一记录在[变更总索引](../changes/README.md)，遵守[项目强制规则](../../AGENTS.md)。[2026-09-13 首次回溯](../changes/2026-09-13-since-09-07.md)覆盖 9 月 7 日后的提交与审查时工作区；其中未提交规则由代码归纳，验证状态单列，不等于真实环境已验收。

当前重点增量包括人员车辆绑定、本人资料与登记照、签到签退人脸核验、照片档案、自然日周期、先学后考与提前结业、学时进度展示。详细适用条件及代码依据以对应编号为入口；首页待考试统计与考试准入尚有差异，不能概括为所有入口均已统一。每次变更只补受影响条目，不重复抄写全部需求。

首期业务闭环包括：

1. 企业、组织、角色和学员基础管理。
2. 课程、视频、培训计划和学习任务管理。
3. 学员在线视频观看、心跳上报、有效学时累计和断线恢复。
4. 学习过程中的随机人脸抽验及异常处置。
5. 结业考试、成绩记录和培训完成状态。
6. 管理端的计划进度、学时和异常统计。

新增需求应记录来源、验收条件、优先级和影响模块，避免以原商业系统代码作为需求实现依据。
