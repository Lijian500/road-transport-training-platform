# Nacos 本地部署说明

本目录记录Nacos的运行约定。当前由`deploy/docker-compose.yml`启动单机Nacos 3.x，供开发环境完成服务注册、发现和配置管理。

## 本地访问

- 控制台：`http://localhost:8088/`
- 服务端地址：`localhost:8848`
- gRPC端口：`9848`

## 使用约定

- 本地环境默认关闭鉴权，禁止将该配置直接用于公网或共享测试环境。
- 应用以环境变量或配置文件读取Nacos地址，不得在Java代码中写死。
- 建议按`dev`、`test`、`prod`创建命名空间；配置按应用名和环境隔离。
- Git仓库只保存非敏感配置模板。数据库密码、令牌私钥等敏感项由环境变量或部署平台注入。
- 共享及生产环境应启用鉴权、TLS、访问控制，并使用高可用集群与外部持久化数据库。

## 启动前检查

复制仓库根目录`.env.example`为`.env`并替换示例密码，然后执行`scripts/start-infra.ps1`。
