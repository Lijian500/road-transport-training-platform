# RabbitMQ 本地部署说明

本目录记录RabbitMQ的运行与消息命名约定。当前由`deploy/docker-compose.yml`启动带管理界面的RabbitMQ，暂不预创建业务交换机和队列，后续由应用以声明式配置幂等创建。

## 本地访问

- AMQP：`localhost:5672`
- 管理台：`http://localhost:15672/`
- 用户名和密码：从仓库根目录`.env`读取

## 消息设计约定

- 交换机建议统一使用`train.<领域>.exchange`。
- 路由键建议使用`train.<领域>.<事件>`。
- 队列建议使用`train.<消费方>.<用途>.queue`。
- 消费者必须支持幂等处理；消息体应携带`eventId`、`eventType`、`occurredAt`和业务标识。
- 学时完成、培训进度汇总、考试结果等跨服务事件使用可靠消息，失败消息进入死信队列。
- 不在消息中传输照片、视频等大文件，只传递对象标识和受控访问地址。

## 安全约定

示例账号只用于本地开发。共享或生产环境应创建独立虚拟主机和最小权限用户，启用TLS，并禁止暴露管理端口到公网。
